# 🔥 Banvenik.ru — Все бани России

Сайт-каталог бань по 94 городам России с 12 типами бань.

## 🚀 Быстрый старт

### 1. Установить Node.js
Скачайте с https://nodejs.org/ (версия LTS)

### 2. Установить зависимости
```bash
npm install
```

### 3. Запустить локально
```bash
npm run dev
```

Откройте http://localhost:4321

### 4. Собрать для продакшена
```bash
npm run build
```

### 5. Загрузить на Cloudflare Pages
```bash
npx wrangler pages deploy dist
```

## 📁 Структура

- `src/pages/` — 94 страницы городов
- `src/components/` — компоненты (Header, Footer, CityCard)
- `src/layouts/` — шаблоны
- `public/` — статические файлы
